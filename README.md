# YTKA DAILY

Сайт-концепт вымышленного агентства новостей «YTKA DAILY» — «самой честной жёлтой прессы», где новости делают утки, пишут утки и читают утки. Учебный проект: макет сделан в Figma, вёрстка выполнена на HTML и CSS без JavaScript.

- Сайт: https://eeevikk.github.io/ytkadaily/

## Разделы сайта

- **Шапка и первый экран** — меню и логотип с багетами, вместе занимают ровно один экран.
- **О нас** — манифест агентства в двух «взрывах» и фотоаппарат.
- **Что мы делаем** — три карточки: свежие «утки», реклама, аналитика.
- **Новости от нашей команды** — четыре новости с аватарками героев.
- **Подписка и контакты** — форма подписки, соцсети и телефон (кнопка «Инфо» в меню ведёт сюда).

## Технологии

HTML, CSS (flex, grid, медиазапросы, `clamp()`), шрифты Anton и Days One (лицензия OFL). Сайт опубликован на GitHub Pages.

## Структура проекта

- `index.html` — вся страница;
- `stylesheets/` — стили: `reset.css`, `fonts.css`, `layout.css`, общий файл `style.css`;
- `fonts/` — файлы шрифтов;
- `images/` — картинки и звёзды (SVG).

## Как запустить

Открыть сайт по ссылке выше или запустить локально в папке проекта:

```bash
python3 -m http.server 8000
```

и открыть http://localhost:8000.
